组播，简单理解

接收组，像一个公共频道

发送端局域网内
接收组238.238.238.238共同订阅的“频道”

点击只播放本页示意，不发送任何网络数据。

一次发送，多方接收。IPv4 的 224.0.0.0–239.255.255.255 是组播地址范围。发送者把数据发给组地址，网络再转给相应接收者。

组地址不是灯 IP。接收组用于同组接收；台灯的实际单播 IP 请看“设备与记录”。网络是否转发仍取决于配置。

TTL 是跳数，不是秒数。它限制数据包可经过的路由跳数；跨网方案使用私网单播，不迁移组播。

这台灯在寻找同伴。抓包看到它向 238.238.238.238:5683 发送 CoAP 发现请求。当前面板直接访问台灯自己的 IP 和 UDP 55001 端口，因此不依赖组播。
